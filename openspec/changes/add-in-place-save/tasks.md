## 2. Core builder module

- [ ] 2.1 Implement `src/core/in-place-save.ts` exporting `buildInPlaceContent(rawContent: string, currentRequests: ParsedRequest[]): { ok: true; content: string; editedCount: number } | { ok: false; error: string }`. Follow the design pseudocode exactly: split raw by `'\n'`; re-parse with `parseHttpFile` for fresh block geometry; refuse (`ok: false`) if the re-parse yields a different request count than `currentRequests` (structural external change); select the edited set from the requests whose `isDirty` marker is set (return `ok: true` with `editedCount: 0` and unchanged content when empty); refuse (`ok: false`) if any selected body line matches `/^#{3,}/` after `trim()`; compute per-selected-request regions (blockStart = nearest `^#{3,}` line above the fresh `lineNumber` else the request line; blockEnd = line before next `^#{3,}` else last line, trailing blank lines trimmed); regenerate via `serializeRequestBlock`; convert `\n` to `\r\n` when `rawContent.includes('\r\n')`; splice bottom-up; return joined content.
- [ ] 2.2 Create `test/core/in-place-save.test.ts` covering every spec scenario: no marked requests → no write (`editedCount === 0`, content unchanged); one of several requests marked → only that block changes and others are byte-identical; multiple marked blocks spliced correctly; form-data request block never rewritten; comments/variables/blank lines outside a block preserved; a marked request reverted to its original body is still rewritten (tombstone) with its body preserved in canonical form; an unmarked request whose on-disk block changed externally is preserved byte-identical; structural change (re-parse count mismatch) returns `ok: false`; separator-less first request gains `### Request 1`; comments above a separator-less first request survive; bare `###` normalized to `### Request N`; named `### Get Users` preserved; header spacing normalized inside a rewritten block (`Content-Type:application/json` → `Content-Type: application/json`); inter-block blank gap preserved; CRLF source stays CRLF and LF source stays LF; EOF trailing-newline convention preserved; marked body containing a `###` line returns `ok: false` with an error.
